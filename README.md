# Personal Engineering Notebook — Offline

A paperless engineering notebook that runs as a static GitHub Pages site and works offline after the first visit.

## Features

- Chapters, sections and unlimited nested subsections with automatic numbering
- Rich-text formatting, text colors and highlights
- Local autosave in the browser
- PDF export for a section or whole chapter
- JSON backup and restore
- Installable Progressive Web App (PWA)

## Publish on GitHub Pages

1. Create a repository and upload these files to its main branch.
2. Open Settings → Pages.
3. Under Build and deployment, select GitHub Actions.
4. After the workflow finishes, open the Pages URL once while online.
5. Use the browser's Install app option. It will then open without internet.

## Important data note

Notes are stored only in the browser on the current device. Use Export backup regularly. Importing the JSON file restores the notebook on another device or browser.
